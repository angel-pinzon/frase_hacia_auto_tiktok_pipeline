# Prompts

Texto propio que costó trabajo o dinero afinar, y que conviene no perder.

- `avatar.txt` — genera retratos de personaje a partir de una foto, conservando
  los rasgos. De aquí salieron los mejores avatares del proyecto.
- `escenas/` — fichas de los clips generados con Veo. Cada una guarda el prompt
  exacto que produjo un clip. Los `.mp4` viven en `output/escenas/` y no se
  versionan por peso, pero con estas fichas se pueden reproducir.

Cada clip de Veo cuesta unos $0.24, así que perder el prompt significa pagar de
nuevo para acertar a ciegas.
