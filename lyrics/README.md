# Letras

Un archivo `.txt` por canción, dentro de una carpeta por personaje:

```
lyrics/<Personaje>/titulo-de-la-cancion.txt
```

**El nombre del archivo es el título** que el pipeline usa para atribuir la cita,
así que debe ser correcto: `sin-medir-distancias.txt` -> "Sin Medir Distancias".

El contenido no se versiona (ver `.gitignore`): son letras con derechos de autor
y este repositorio es publico. Cada quien aporta su propio corpus.
