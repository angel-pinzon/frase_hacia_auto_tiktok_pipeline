# Recursos por personaje

```
assets/<Personaje>/
├── ref_audio.wav    # 5-15 s de habla limpia del artista
├── ref_text.txt     # transcripcion literal de ese audio
└── avatar.jpg       # foto frontal, boca cerrada, >1900 px de alto
```

Los audios y las fotos no se versionan (ver `.gitignore`): son material con
derechos. El `README.md` de la raiz explica como obtenerlos y que criterios
seguir para que la clonacion y la animacion salgan bien.
